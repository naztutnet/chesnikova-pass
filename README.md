# CHESNIKOVA PASS

Адаптивный веб-сайт для оформления гостевых пропусков в Amedia PassOffice. Один интерфейс работает на телефоне и компьютере: на мобильном используется нижняя навигация, на широком экране — постоянное боковое меню.

## Локальный запуск

Требуется Node.js 24+ (используется встроенный `node:sqlite`).

```bash
ALLOW_DEMO_AUTH=true PASSOFFICE_PROVIDER=demo npm start
```

Открыть `http://localhost:4173`.

## Текущий статус

- Реализован адаптивный пользовательский путь и сохранение черновика в браузере.
- Добавлен свободный текстовый ввод: дата, место и несколько гостей разбираются в тот же редактируемый черновик, что и ручная форма.
- Поля прототипа сверены с формой разовой заявки PassOffice.
- В репозитории сохранён экспериментальный сервер из Telegram-прототипа: он валидирует форму, шифрует персональные данные в SQLite и защищает создание от повторной отправки. GitHub Pages его не запускает; для рабочего сайта нужна отдельная веб-авторизация.
- Демо-провайдер позволяет проверить полный локальный сценарий без создания реального пропуска.
- Адаптер официального Open API заблокирован до получения Swagger, URL IntegrationServer и API-ключа конкретной установки.

## Публикация демо на GitHub Pages

```bash
npm run build:pages
```

GitHub Actions публикует содержимое `dist` после каждого push в `main`. GitHub Pages размещает только статический веб-интерфейс: он сохраняет черновик в браузере и показывает демонстрационный результат, но не запускает сервер и не создаёт реальную заявку в PassOffice.
